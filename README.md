# Багийн квиз

Олон төхөөрөмжөөс зэрэг тоглох багийн асуулт хариултын тоглоом. Node.js, Express, Socket.IO.

## Нэвтрэх
- Сайт руу ороход нууц код асууна.
- **Админ:** `ADMIN_CODE` орчны хувьсагч. Тохируулаагүй бол `536478`.
- **Ахлагч нар:** админ «Бүртгэл нээх» дарахад ахлагч бүрд санамсаргүй 6 оронтой код үүснэ. Админы дэлгэц дээр харагдана.

## Компьютер дээрээ ажиллуулах
```bash
npm install
npm start
# http://localhost:3000
```

## Render дээр байршуулах
1. Энэ хавтасыг GitHub дээр шинэ repository болгон push хийнэ (private байх нь зүйтэй).
2. render.com → **New** → **Web Service** → GitHub repository-гоо сонгоно.
3. Тохиргоо:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance type: Free
4. **Environment** хэсэгт `ADMIN_CODE` = `536478` нэмнэ.
5. **Create Web Service**. Хэдэн минутын дараа `https://<нэр>.onrender.com` хаяг гарна.

Эсвэл **New → Blueprint** сонгоход `render.yaml` файлаас тохиргоо автоматаар уншигдана.

## Анхаарах
- Render-ийн үнэгүй багц 15 минут хандалтгүй бол унтаж, дахин сэрэхэд 30–60 секунд хүлээлгэнэ. Тоглолтын өмнө сайтаа нэг нээгээрэй.
- Үнэгүй багцын диск түр зуурынх: сервер дахин эхлэх эсвэл шинээр deploy хийхэд асуултууд, тоглолт арилна. Асуултуудаа «Одоогийн асуултуудыг энд гаргах» товчоор текст болгон хадгалж, дараа нь «Олноор нь оруулах»-аар буцааж оруулна.
- Байнга хадгалах бол Render-ийн төлбөртэй Persistent Disk холбоод `DATA_FILE=/var/data/state.json` гэж тохируулна.
